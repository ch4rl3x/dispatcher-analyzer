Shows possible incoming dispatchers above suspend functions and execution dispatchers at suspend calls. Hover for uncertainty details; click a colored dispatcher name to navigate to its source evidence.

Under Tools > Dispatcher Analyzer, show all call badges, only calls that set a dispatcher, or none (default). Declaration badges require a project code call and remain enabled while IDE inlay hints are enabled.

Main is red, Default green, IO yellow, identified custom dispatchers purple, and Unknown gray. A partial entry means some known work can run elsewhere. Badges are editor hints and never modify source code.
