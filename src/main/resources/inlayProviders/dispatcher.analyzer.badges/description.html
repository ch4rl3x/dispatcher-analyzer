Shows possible incoming dispatchers above suspend functions and execution dispatchers at suspend calls. Hover over a badge for evidence and uncertainty.

Call badges are off by default. Enable them under Tools > Dispatcher Analyzer. Declaration badges remain enabled while IDE inlay hints are enabled.

Main is red, Default green, IO yellow, identified custom dispatchers purple, and Unknown gray. A partial entry means some known work can run elsewhere. Badges are editor hints and never modify source code.
